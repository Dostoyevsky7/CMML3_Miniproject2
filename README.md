# CMML3_Miniproject2

# scRNA-seq Clustering Benchmark Using Synthetic PBMC Data

This repository contains the R scripts used for the mini-project report:

**Benchmarking clustering methods on synthetic single-cell RNA-seq data with controlled cluster separability and cell-type imbalance**

## Project overview

Single-cell RNA sequencing (scRNA-seq) is widely used to identify cell types and cell states through clustering analysis. However, clustering performance can be influenced by the underlying data structure, including how well cell populations are separated and whether cell-type proportions are balanced.

This project uses **scDesign3** to generate synthetic PBMC-like scRNA-seq datasets with known ground-truth cell-type labels. The synthetic datasets were designed to test how two factors affect clustering reliability:

1. **Cluster separability**
   - High separability
   - Low separability

2. **Cluster size composition**
   - Balanced
   - Moderately imbalanced
   - Extremely imbalanced

Four clustering methods were benchmarked:

- Hierarchical clustering
- k-means clustering
- Leiden clustering
- Louvain clustering

The methods were evaluated using:

- Adjusted Rand Index (ARI)
- Normalized Mutual Information (NMI)
- Silhouette score
- UMAP visualization

## Pipelines

The original data was downlaoded from the official 10x Genomics dataset repository, https://cf.10xgenomics.com/samples/cell-exp/1.1.0/pbmc3k/pbmc3k_filtered_gene_bc_matrices.tar.gz.


### The `GenerateData_repeats.R` used scDesign3 to synthesize datasets from the original data：

1. The script first loads the original PBMC3K 10X Genomics count matrix and processes it using a standard Seurat workflow, including quality control, normalization, highly variable gene selection, PCA, clustering, and UMAP visualization.

2. Marker genes are identified for each Seurat cluster, and the clusters are manually annotated into major PBMC cell types. The annotated PBMC3K dataset is used as the biological reference for simulation.

3. Two reference subsets are constructed to represent different levels of cell-type separability. The high-separability subset contains B cells, CD14 monocytes, and NK cells, while the low-separability subset contains naive CD4 T cells, memory CD4 T cells, and CD8 T cells.

4. Each reference subset is converted into a SingleCellExperiment object and used to fit a scDesign3 model. The model captures cell-type-specific gene expression patterns and gene-gene correlation structure.

5. Synthetic datasets are generated under six simulation conditions, combining two separability settings with three cluster-size composition settings: balanced, moderately imbalanced, and extremely imbalanced.

6. For each condition, five independent simulation replicates are generated. Each synthetic dataset contains 3,000 cells with known true cell-type labels.

7. The script saves the simulated count matrices and metadata as RDS files, together with marker gene tables, fitted scDesign3 reference models, cell-type composition summaries, quick UMAP quality-check plots, and session information.

This script focuses on synthetic data generation and initial quality checking. It does not perform downstream clustering benchmarking.


### The `PlotData_repeats.R` did downstream clustering benchmark for scDesign3 synthetic PBMC datasets:

1. The script loads the synthetic RDS files generated by the scDesign3 simulation script. These files represent six simulation conditions across different levels of cell-type separability and cluster-size imbalance, with five replicates per condition.

2. Each synthetic dataset is converted into a Seurat object and processed using a standard workflow, including normalization, highly variable gene selection, scaling, PCA, and UMAP dimensionality reduction.

3. Four clustering methods are applied to each dataset: Louvain clustering, Leiden clustering, k-means clustering, and hierarchical clustering.

4. The predicted clusters are compared with the true simulated cell-type labels. Clustering performance is evaluated using Adjusted Rand Index, Normalized Mutual Information, silhouette score, majority-mapped accuracy, confusion matrices, and per-cell-type recall.

5. The script saves UMAP plots coloured by true cell-type labels and predicted clustering labels, allowing visual comparison between the simulated ground truth and clustering results.

6. Evaluation results are combined across all datasets, methods, and replicates. The script summarizes the mean and variation of clustering performance across simulation replicates for each separability and composition condition.

7. The main output files include full clustering metric tables, per-cell-type recall tables, synthetic data sanity-check summaries, confusion matrices, processed Seurat objects, and summary plots for ARI, NMI, silhouette score, and recall.

This script focuses on benchmarking clustering performance. It does not generate synthetic data, so the scDesign3 simulation script should be run first.
